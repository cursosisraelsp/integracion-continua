# 🚀 Práctica: Mi Primer Corrector Automático

¡Bienvenido/a a tu primera práctica con integración continua! En este repositorio aprenderás a colaborar con un **asistente virtual** (GitHub Actions) que corregirá tu trabajo automáticamente cada vez que subas código.

---

## 🎯 ¿Cuál es tu misión?

Tu objetivo es crear la estructura básica de tu primera página web. 

Para dar por superada la práctica, debes conseguir que el **robot corrector** revise tu código y te dé el **visto bueno en verde (✅)**.

---

## 📋 Pasos para completar la tarea

1. **Crea el archivo principal de la web:**  
   En la raíz de este proyecto, crea un archivo llamado exactamente `index.html`.

2. **Escribe un código básico:**  
   Dentro de tu `index.html`, escribe una estructura HTML sencilla o al menos un título con tu nombre.

3. **Sube tus cambios a GitHub:**  
   Guarda tu archivo y realiza el envío de tu código mediante la consola o la interfaz de GitHub:
   ```bash
   git add .
   git commit -m "Añadido archivo index.html"
   git push
